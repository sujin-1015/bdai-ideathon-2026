# 인게이지먼트 넛지 시스템 — 프로토타입

BDAI LMS 활성화 아이디어톤 제안서 "저빈도·이탈 사용자 재참여를 위한 AI 기반 인게이지먼트 넛지 시스템"의 핵심 기능을 보여주는 인터랙티브 웹 프로토타입입니다.

## 화면 구성

1. **리포트 페이지** — page_view 발생 후 참여 부족을 감지해 이탈 감지 하이라이트 카드가 자동 노출되는 흐름
2. **로그인 · 저빈도 리마인더** — 직전 월 세션 1회 사용자에게 로그인 시 개인화 리마인더가 노출되는 흐름
3. **운영진 대시보드** — 회원 유형·기능별 참여 현황과 자동 넛지 규칙 운영 현황

대시보드에 쓰인 수치는 BDAI가 제공한 GA4·내부 데이터 참고자료(2026.4.5–7.24, 4월·7월은 부분 기간) 기준입니다.

## 실행

`index.html`을 브라우저로 열면 바로 동작합니다. 별도 빌드나 의존성이 없습니다.
